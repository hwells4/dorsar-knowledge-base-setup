# Getting SharePoint within reach

Read this when step 1 found nothing to list. Dorsar's files are in SharePoint; the agent reads them as a normal folder once OneDrive syncs the library to the machine. Give one instruction at a time and confirm each works.

## Steps for Bill (Windows)

1. Open the SharePoint site in the browser, go to the document library that holds the private investment folders, and click "Sync" in the toolbar. OneDrive starts syncing that library to the PC.
2. In File Explorer, find the new folder under "Dorsar Investment Management" (it appears beside OneDrive in the left pane).
3. Right-click that folder and choose "Always keep on this device". Without this, files are cloud-only placeholders and every read triggers a download.
4. Tell the agent the folder path. It looks like `C:\Users\<name>\Dorsar Investment Management\<Library name>`.

Repeat for each library the work needs (investments, entity financials, diligence) once the interview names them.

## How to say it

"I cannot see any of your SharePoint files from here yet, so I would be guessing about how they are organised. Two minutes fixes that: open the library in your browser, click Sync, and it shows up as a normal folder on this PC. Then I can look at the real structure instead of asking you to describe it."

## If the SharePoint team member is on the call

Ask them which libraries exist, which ones the analyst and the second teammate can see, and whether anything in the investment library sits behind restricted permissions. That answer feeds the off-limits list directly.

## Done when

You can list the library that holds the investment folders, or you have the exact library name and the step that is blocking sync written down for the IT contact.
